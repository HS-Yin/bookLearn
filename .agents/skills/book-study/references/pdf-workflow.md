# On-demand PDF workflow

Use this reference only when the active book includes a PDF and the answer needs source
verification, page content, equations, figures, or tables.

## Default behavior

- Never read the entire PDF just because it is present.
- Prefer the user's page range, subsection, excerpt, or screenshot.
- Use text extraction to locate relevant passages when the PDF is searchable.
- Render the relevant page when layout, equation structure, symbols, diagrams, or tables
  affect meaning.
- Cite page numbers in `notes.md` and distinguish direct book evidence from inference.

## Reliability checks

Treat extraction as unreliable when text is missing, characters are garbled, columns are
interleaved, formulas lose structure, or figures/tables are absent. For scanned pages or
uncertain technical notation:

1. Identify the exact page and uncertain element.
2. Tell the learner that the source cannot be read reliably.
3. Request a page image, screenshot, copied excerpt, or the learner's description.
4. Continue only from reliable evidence; never silently repair or invent notation.

## Scope discipline

When answering a question, inspect only the smallest relevant page range. Do not convert
the PDF into a searchable corpus or create extracted full-book text files. If the user
explicitly requests a larger extraction or chapter summary, confirm the requested range
and purpose first, then keep the output proportional.
