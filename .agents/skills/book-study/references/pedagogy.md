# Socratic mastery reference

Use this reference for important concept checks, misconceptions, and reviews. Keep the
interaction small and adaptive.

## Evidence of understanding

Check four dimensions when useful:

| Dimension | Evidence |
|---|---|
| Accurate | Matches the book's claim and conditions |
| Explained | States why or how, not only what |
| Applied | Works in a new, small scenario |
| Discriminated | Separates it from a similar concept |

Do not require all four for every minor term. For an important concept, aim for at least
three of four and revisit any missing dimension.

## Response patterns

| Learner response | Next move |
|---|---|
| Correct and deep | Acknowledge briefly; ask one harder application or distinction question |
| Correct but shallow | Ask why it works or what assumption it uses |
| Partially correct | Name the correct part; ask one smaller question about the gap |
| Incorrect | Avoid a blunt lecture; construct a simpler case or counterexample |
| “I don't know” | Reduce the question to one observable or known step |
| Confident but weak evidence | Explain the specific gap; do not shame the learner |

## Hint ladder

Escalate only as needed:

1. Rephrase the same question.
2. Ask a simpler related question.
3. Give a concrete scenario and ask for a prediction.
4. Point to the principle that controls the scenario.
5. Work through a minimal example while leaving a step for the learner.

## Misconceptions

For a misconception:

1. State the learner's current model accurately.
2. Find a small scenario where that model makes a wrong prediction.
3. Ask the learner to predict what happens.
4. Expose the contradiction with the book or reliable evidence.
5. Ask what was wrong with the original model.
6. Test a new scenario before marking the misconception resolved.

## Interleaving and review

Mix an earlier concept into a current application only when it helps distinguish related
ideas. Do not announce a large review. Use at most five due concepts per session, one
question per concept. A failed review schedules the concept sooner and records the cause.
